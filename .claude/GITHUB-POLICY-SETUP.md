**Time to Setup**: < 5 minutes

## Quick Start

Run this in PowerShell (from repository root):

```powershell
# 1. Install the pre-push hook
bash .claude/scripts/install-pre-push-hook.sh

# 2. Verify it's installed
Get-Item .git/hooks/pre-push -ErrorAction SilentlyContinue
# Expected: File exists with executable permissions

# 3. Test with a dummy commit
git commit --allow-empty -m "test: verify pre-push hook is active"
git push origin HEAD --no-verify  # or push normally to trigger hook

# Done! Policy is now active.
```

## Detailed Setup Steps

### Step 1: Verify Prerequisites

Before installing the policy, ensure you have:

```bash
# Check git is installed
git --version
# Expected: git version 2.30+

# Check bash is available
bash --version
# Expected: GNU bash, version 4.4+

# Check you're in the right repository
git remote -v
# Expected: origin = https://github.com/lkswally/Claude-Atlas.git

# Check .git/hooks directory exists
ls -la .git/hooks/
# Expected: hooks directory with pre-existing files (pre-commit, prepare-commit-msg, etc)
```

### Step 2: Install the Pre-Push Hook

Create the hook installation script:

```bash
# From repository root, run:
cat > .claude/scripts/install-pre-push-hook.sh << 'EOF'
#!/bin/bash
# install-pre-push-hook.sh — Install GitHub Policy pre-push hook

set -euo pipefail

REPO_ROOT="$(git rev-parse --show-toplevel)"
HOOK_DIR="$REPO_ROOT/.git/hooks"
HOOK_FILE="$HOOK_DIR/pre-push"
POLICY_SCRIPT="$REPO_ROOT/.claude/scripts/pre-push-check.sh"

echo "🔒 Installing GitHub Policy pre-push hook..."
echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"

# Verify pre-push-check.sh exists
if [ ! -f "$POLICY_SCRIPT" ]; then
    echo "❌ ERROR: $POLICY_SCRIPT not found"
    exit 1
fi

# Create the pre-push hook file
cat > "$HOOK_FILE" << 'HOOK'
#!/bin/bash
# GitHub Policy pre-push hook
# Auto-generated by install-pre-push-hook.sh

REPO_ROOT="$(git rev-parse --show-toplevel)"
POLICY_SCRIPT="$REPO_ROOT/.claude/scripts/pre-push-check.sh"

# Run the pre-push checks
bash "$POLICY_SCRIPT" "$@"
exit $?
HOOK

# Make hook executable
chmod +x "$HOOK_FILE"

echo "✅ Pre-push hook installed successfully"
echo ""
echo "Location: $HOOK_FILE"
echo "Policy script: $POLICY_SCRIPT"
echo ""
echo "Next steps:"
echo "  1. Test the hook: git commit --allow-empty -m 'test: hook'"
echo "  2. Try to push: git push origin HEAD"
echo "  3. Hook should run and display check results"
echo ""
EOF

chmod +x .claude/scripts/install-pre-push-hook.sh
bash .claude/scripts/install-pre-push-hook.sh
```

### Step 3: Verify Installation

After installation, verify the hook is in place:

```bash
# Check hook file exists
ls -la .git/hooks/pre-push
# Expected: -rwxr-xr-x (executable permissions)

# View hook contents
cat .git/hooks/pre-push
# Expected: script that calls pre-push-check.sh
```

### Step 4: Test the Policy

Create a test commit to verify the policy works:

#### Test Case 1: Clean Commit (Should Pass)

```bash
# Stage a safe file
echo "# Test commit" >> .claude/.test-file.txt
git add .claude/.test-file.txt

# Commit
git commit -m "test: verify pre-push hook is working"

# Try to push (hook should run and PASS)
git push origin HEAD
# Expected output:
# 🔒 GitHub Policy: Pre-Push Security Check
# ✅ PASS — API keys/tokens detection
# ✅ PASS — Hardcoded credentials detection
# ✅ PASS — .gitignore coverage
# ✅ PASS — Large file detection
# ✅ PASS — Cache/temp file detection
# ✅ All checks passed. Safe to push.

# Clean up
git reset --soft HEAD~1
git reset HEAD .claude/.test-file.txt
rm .claude/.test-file.txt
```

#### Test Case 2: Secret Detection (Should Fail)

```bash
# Stage a file with a fake secret
echo "api_key = sk_test_12345" > .claude/.secret-test.txt
git add .claude/.secret-test.txt

# Commit
git commit -m "test: verify secret detection"

# Try to push (hook should run and FAIL)
git push origin HEAD
# Expected output:
# 🔒 GitHub Policy: Pre-Push Security Check
# ❌ FAIL — API keys/tokens detection
# Found potential secret in: .claude/.secret-test.txt
# ❌ Pre-push checks failed. Fix issues before pushing.

# Clean up
git reset --soft HEAD~1
git reset HEAD .claude/.secret-test.txt
rm .claude/.secret-test.txt
git reset HEAD --  # unstage the commit
```

## Troubleshooting

### Issue: "Permission denied" when running pre-push hook

**Cause**: Hook file is not executable  
**Fix**:
```bash
chmod +x .git/hooks/pre-push
ls -la .git/hooks/pre-push  # verify -rwxr-xr-x
```

### Issue: "pre-push-check.sh: No such file or directory"

**Cause**: Hook is looking for script in wrong path  
**Fix**: Reinstall the hook
```bash
bash .claude/scripts/install-pre-push-hook.sh
```

### Issue: Hook runs but shows bash errors

**Cause**: .claude/scripts/pre-push-check.sh has issues  
**Fix**: Verify the script
```bash
bash -n .claude/scripts/pre-push-check.sh  # check for syntax errors
bash .claude/scripts/pre-push-check.sh origin HEAD  # run manually
```

### Issue: Cannot push even legitimate commits

**Cause**: A check is too strict or misconfigured  
**Fix**: Review the check output and either:
- Fix the staged files (recommended)
- Adjust the check pattern in pre-push-check.sh
- Temporarily bypass with `git push --no-verify` (last resort)

### Issue: Hook interferes with GitHub Actions or CI

**Cause**: CI system is trying to push without the hook environment  
**Fix**: The hook only runs locally. CI can safely push using:
```bash
git push --no-verify  # or configure CI to not use local hooks
```

## Disabling the Policy

### Temporary Disable (Single Push)

```bash
# Push without running the pre-push hook
git push origin <branch> --no-verify
```

### Permanent Disable

```bash
# Remove the hook
rm .git/hooks/pre-push

# Verify it's removed
ls .git/hooks/pre-push 2>&1
# Expected: "No such file or directory"
```

### Re-enable After Disabling

```bash
bash .claude/scripts/install-pre-push-hook.sh
```

## Integration with CI/CD

### GitHub Actions

If your GitHub Actions workflow needs to push code, add to your workflow:

```yaml
- name: Push changes
  run: git push origin main --no-verify
```

The `--no-verify` flag skips the local pre-push hook (which won't exist in the CI environment).

### Prevent Bypasses

To enforce policy even in CI, store secrets as GitHub Secrets and never commit them:

```yaml
- name: Configure credentials
  env:
    API_KEY: ${{ secrets.API_KEY }}
  run: |
    echo "API_KEY=$API_KEY" > .env.local
    # .env.local is in .gitignore, won't be committed
```

## Policy Audit & Monitoring

### View Push History

```bash
git log --all --oneline | head -20
```

### Filter by Commit Type

```bash
# Show only feature commits pushed via this policy
git log --oneline --grep="^feat"

# Show only security-related commits
git log --oneline --grep="security\|secret"
```

### Check Hook Execution Logs

The pre-push hook doesn't write to a log file by default, but you can add logging:

```bash
# Edit .git/hooks/pre-push to add logging
cat >> .git/hooks/pre-push << 'EOF'

# Optional: log to file
{
    echo "$(date): Push to $1/$2"
    echo "Checks: $(if [ $? -eq 0 ]; then echo "PASSED"; else echo "FAILED"; fi)"
} >> .claude/logs/pre-push.log
EOF
```
